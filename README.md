# Jeanius Power Washing Demo

Static GitHub Pages-ready demo site for Jeanius Power Washing.

## Files included

- `index.html` — full demo site
- `styles.css` — styling and responsive layout
- `script.js` — rough estimate calculator, property-preview mockup, and FAQ chat demo
- `.nojekyll` — tells GitHub Pages to serve the site directly without Jekyll processing

## Best repo name

I recommend:

`jeanius-power-washing-demo`

## Upload to GitHub Pages

1. Create a new **public** GitHub repository.
2. Name it `jeanius-power-washing-demo`.
3. Upload all files from this folder to the root of the repo.
4. Commit the files to the `main` branch.
5. In GitHub, go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select **main** as the branch and **/(root)** as the folder.
8. Save.
9. Wait for GitHub Pages to publish the site.
